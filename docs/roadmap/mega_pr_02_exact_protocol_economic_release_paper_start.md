## Mandatory scope

1. Establish one genesis-bound protocol/program registry and strict current provider contracts.
2. Use only hardened v0 compilation plus final exact simulation.
3. Bind immutable message hash, ALT state, blockhash, rooted slots, accounts and compute policy.
4. Decode raw state inside the trusted boundary and use integer-only conservative economics for all fees, rent, tips and liabilities.
5. Replace competing release/qualification authorities with one signed materialized-evidence manifest and one evaluator.
6. Remove metadata-only gates, retired PR/MPR gates and debt overlays from the capability path.
7. Build from an offline hash-locked wheelhouse with digest-pinned images and full-SHA GitHub Actions.
8. Produce SBOM, provenance, signatures, vulnerability and license evidence.
9. Require a real 72-hour paper qualification from durable unique cycles and trusted time, without replay or synthetic contamination.
10. Require independent signed review and evidence freshness policy before paper promotion.

## Definition of done

- A one-byte mutation invalidates the transaction/evidence chain.
- Missing, symlinked, arbitrary, oversized or stale artifacts cannot qualify.
- Caller-supplied duration and repeated one-cycle replay cannot satisfy 72-hour qualification.
- Official protocol vectors pass and near-miss protocol values fail.
- Malformed, zero, cross-asset-loss or incomplete economics never become proven profit.
- Clean offline build reproducibly creates the reviewed wheel/image artifacts.
- All GitHub Actions used by release/required checks are pinned to reviewed full SHAs.
- Production debt closure requires accepted immutable evidence, not unsigned boolean overlays.
- Promotion can end only at `production-paper-ready`; live, signer and sender capabilities remain unavailable.

## Safety boundary

This PR must not:

- enable live trading;
- enable private-key loading;
- enable signer IPC;
- enable transaction submission;
- enable Jito submission;
- mark the system production-ready;
- add an unrestricted live state.

- E. 72-hour paper qualification and paper-only promotion.
