# WG-19 — CEX и derivatives market data

Статус: **PLANNED_NOT_IMPLEMENTED**. Этап: D. Режим: shadow_only.

Зависимости: WG-03, WG-04, WG-05, WG-22.

## Результат

Отдельные replayable public market-data packs: spot books, funding, futures/options.

## Существующие владельцы

- O22: `src/market_data_evolution/contracts.py` — InstrumentIdentity; RawObservation; AvailabilityProof; StateSnapshot; ReplayManifest
- O23: `src/market_data_evolution/packs.py` — CrossMarketPack; all_cross_market_packs

## Шаги будущей реализации

1. Переиспользовать CCXT/Cryptofeed только для read-only data; protocol-native sequence/checksum приоритетны.
2. Instrument key хранит contract multiplier, expiry, underlying, margin/settlement assets, session и mark/index distinction.
3. Записывать reconnect gaps и наблюдаемую задержку; synthetic aggregation не заменяет venue L2 depth.

## Приёмка

- Book checksum/sequence failures инвалидируют depth.
- Data access не даёт trading access; spot/perp symbols не склеиваются.

Сценарии: T62, T63, T64; определения в `../06_ACCEPTANCE_RU.md`.

## Ограничения

Один exchange и ограниченный watchlist; no private account/order APIs.

## Когда остановить admission

Region/key/license/channel ambiguity → access-not-verified; no assumption every endpoint free.

Не создаёт live authorization. Размер diff и оценку труда определить после обновления baseline; новые owner дубликаты не вводить.
