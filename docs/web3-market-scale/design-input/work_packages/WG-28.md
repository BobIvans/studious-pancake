# WG-28 — Поэтапная shadow release qualification

Статус: **PLANNED_NOT_IMPLEMENTED**. Этап: E. Режим: shadow_only.

Зависимости: WG-09, WG-13, WG-14, WG-15, WG-16, WG-17, WG-20, WG-23, WG-24, WG-25, WG-26, WG-27.

## Результат

Capability matrix и evidence bundles по каждому независимому pack.

## Существующие владельцы

- O04: `src/strategy/arbitrage_graph.py` — UniversalArbitrageGraph; CircularGraphCandidateDetector; CircularShadowRoute
- O05: `src/strategy/market_graph_ingest.py` — ShadowMarketBinding; ShadowMarketGraphIngest
- O17: `src/strategy/strategies.py` — OrderbookAmmStrategy
- O22: `src/market_data_evolution/contracts.py` — InstrumentIdentity; RawObservation; AvailabilityProof; StateSnapshot; ReplayManifest

## Шаги будущей реализации

1. Каждый pack проходит contract/math/state/economics/replay gates отдельно; экспериментальный pack не повышает статус остальных.
2. В PR отчёте указать scope, changed owners, pinned corpus, tests, remaining external blockers и rollback.
3. Проверить imports/config/startup на отсутствие sender/signer/submission/live permission изменений.

## Приёмка

- Нельзя назвать whole-Web3 coverage завершённым из-за прохождения одной Solana fixture.
- Ни один gate не включает live или OrderbookAmmStrategy.

Сценарии: T87, T88, T89; определения в `../06_ACCEPTANCE_RU.md`.

## Ограничения

Итоговая сводка может содержать disabled/blocked packs; done определяется для declared scope.

## Когда остановить admission

Failure/unknown остается explicit blocked; не маскировать тестовыми заглушками.

Не создаёт live authorization. Размер diff и оценку труда определить после обновления baseline; новые owner дубликаты не вводить.
