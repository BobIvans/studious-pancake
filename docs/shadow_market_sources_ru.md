# Источники данных и orderbook-инструменты для shadow-графа

Дата проверки первичных материалов: 2026-10-02. В каталоге 43 записей; 4 discovery parsers реализованы. Оставшиеся записи — источники/инструменты для подключения или кандидаты с непроверенным доступом, а не работающие feeds.

Весь финансовый рынок не покрыт одним бесплатным API. Покрытие измеряется отдельно: discovered markets → явно привязанные markets → точные котировки → свежие котировки. Только canonical exact observations с integer amount coupling попадают в граф; цены/OHLCV/TVL и агрегированные opaque routes не становятся исполнимыми рёбрами.

Открытый SDK не означает бесплатный hosted RPC или gRPC. Источники с непроверенными условиями не считаются бесплатными и не подключаются автоматически. CEX, EVM и долгосрочные инструменты находятся в отдельных settlement domains.

## Как подключать

1. Начать с [offline demo](../scripts/shadow_market_graph_demo.py): `python -m scripts.shadow_market_graph_demo`.
2. Использовать `PublicMarketDiscovery` с уже допущенным bounded `Transport`; добавить profiles/budgets у существующего provider-governance owner до runtime-подключения. Не создавать свой rate limiter или transport.
3. Подтвердить адрес/owner и mint pair underlying venue, закрепить decoder и read-only subscription у текущего владельца. Discovery сам не создаёт bindings.
4. Подать в `ShadowMarketGraphIngest` canonical `MarketObservationV2` с точными входами/гарантированными выходами, genesis, cursor/epoch, request fingerprint и response hash. Sizing и non-monotonic amount grid остаются у PR118.
5. Завершить backfill, опубликовать batch, проверить coverage/staleness/slot spread и вызвать существующий 3/4-hop detector. Неполные наборы требуемых markets блокируют candidates.

Phoenix Legacy/OpenBook V2/Manifest перечислены как инструменты для будущей квалификации. Current repository adapters Phoenix/OpenBook остаются fixture-only; orderbook admission в bridge закрыт, `OrderbookAmmStrategy` disabled. Sender/signer/submission/live authorization не добавлены.

## Проверка доступности

В этой среде четыре прямых read-only HTTPS smoke-запроса вернули transport errors. Совместимость живых payloads и доступность endpoints не подтверждены. Реализованы детерминированные fixture tests, явные HTTP/schema/limit errors и provenance receipts; эти результаты не выданы за live coverage.
