# MPR-45 — Operational Truth, Dynamic Release Gates, SLO and Multi-Day Soak

This branch starts the MPR-45 workstream from the master production-ready closure pack.

## Goal

Turn production readiness from declared booleans into materialized evidence generated by the real installed runtime under realistic load, failure, restart and recovery conditions.

## Initial fail-closed scope

This starter patch adds verifier entrypoints only. They are intentionally conservative and must not mark the repository ready until real artifacts exist.

Planned implementation checkpoints:

1. release claims derived from real artifacts/probes, not self-declared booleans;
2. complete release bundle: source/wheel/image/dependency/SBOM/provenance/config/schema/provider/test/soak/fault/recovery artifacts;
3. service SLO definitions and readiness derived from service truth;
4. correlated observability with bounded metric/log cardinality;
5. sender-free live-data shadow soak with unique cycle identity;
6. fault-injection, restart/upgrade, backup/restore and alert qualification;
7. independent evidence verification and evidence-aware production debt closure.

## Safety boundary

This branch must remain sender-free and live-disabled. It must not enable signer, private-key loading, transaction submission, Jito send paths, canary activation or unrestricted live mode.

## Follow-up implementation

Replace the scaffold scripts with validators that load concrete release-bundle artifacts, recompute digests, verify freshness/signatures where required and fail closed on missing, stale, synthetic or self-declared evidence.
