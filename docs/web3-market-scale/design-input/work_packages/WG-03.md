# WG-03 — Каталог бесплатного доступа и доказанное покрытие

Статус: **PLANNED_NOT_IMPLEMENTED**. Этап: A. Режим: shadow_only.

Зависимости: WG-01.

## Результат

Расширение одного source registry с access/rights/quota/revision/coverage статусами.

## Существующие владельцы

- O06: `src/market/source_catalog.py` — MarketSourceCatalog; load_market_source_catalog
- O22: `src/market_data_evolution/contracts.py` — InstrumentIdentity; RawObservation; AvailabilityProof; StateSnapshot; ReplayManifest

## Шаги будущей реализации

1. Импортировать 43 baseline records и отдельно рассмотреть watchlist.
2. По первичным документам фиксировать API tier, ключ, лимиты, условия хранения/перераспространения, checked_at и unresolved поля.
3. Для каждого source определить роль: discovery/reference/raw state/exact quote/indexer/tool; не удваивать underlying liquidity.

## Приёмка

- Free, open-source и unknown различаются.
- Числа discovered/bound/decoded/exact/fresh относятся к versioned configured universe; global denominator unknown.

Сценарии: T06, T07, T08; определения в `../06_ACCEPTANCE_RU.md`.

## Ограничения

Не массовый crawler; catalog max 128 текущего owner, рост — отдельная проверка.

## Когда остановить admission

Изменение тарифа, лицензии или schema переводит соответствующий source в reverify; нельзя считать ошибку пустым успешным ответом.

Не создаёт live authorization. Размер diff и оценку труда определить после обновления baseline; новые owner дубликаты не вводить.
