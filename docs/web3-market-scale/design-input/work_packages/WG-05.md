# WG-05 — Согласованный локальный state engine

Статус: **PLANNED_NOT_IMPLEMENTED**. Этап: A. Режим: shadow_only.

Зависимости: WG-02, WG-04.

## Результат

Checkpoint + event replay и invalidation над текущими stream contracts.

## Существующие владельцы

- O02: `src/market/observations.py` — MarketObservationV2; exact_output_for
- O03: `src/market/streams.py` — WatermarkedObservationBuffer; FanoutMatrix; DurableCursorStore
- O05: `src/strategy/market_graph_ingest.py` — ShadowMarketBinding; ShadowMarketGraphIngest
- O22: `src/market_data_evolution/contracts.py` — InstrumentIdentity; RawObservation; AvailabilityProof; StateSnapshot; ReplayManifest

## Шаги будущей реализации

1. Определить полные account sets для одного venue: pool, vault, mint, ticks/bins/books/oracle при необходимости.
2. Versioned snapshots связывают state hash, decoder revision, genesis, context slot/block, commitment, source cursor и available_at.
3. Cursor resume восстанавливает состояние через snapshot/backfill; gaps, reorg, correction, generation change инвалидируют зависимые evaluations.

## Приёмка

- После restart cursor без state не создаёт quote coverage.
- Идентичный replay даёт одинаковый state и graph evidence; snapshot с пробелом не публикует candidates.

Сценарии: T12, T13, T14, T15, T16; определения в `../06_ACCEPTANCE_RU.md`.

## Ограничения

Текущий ingest window ≤512 events/epoch; постоянный daemon только через проверенные checkpoint/rollover, не снятие cap.

## Когда остановить admission

Неполные аккаунты, mixed slots/generations, clock future, checksum gap → non-admissible state.

Не создаёт live authorization. Размер diff и оценку труда определить после обновления baseline; новые owner дубликаты не вводить.
