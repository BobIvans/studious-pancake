# OP-10 — Debt refinance and collateral swap

**Гипотеза для исследования, не готовая стратегия. Прибыльность и доступный объём неизвестны.**

| Поле | Постановка |
| --- | --- |
| Класс | SERVICE_OR_COST_SAVING |
| Роль flashloan | INTRA_TX_BRIDGE |
| Горизонт | TX_WITH_PERSISTENT_NEW_DEBT |
| Приоритет исследования | P2 |

## Что искать

Financing spread or borrower demand.

## Что требуется доказать

Interest savings exceed switch cost while health and permissions hold.

## Минимальные данные

borrow terms; collateral rights; fees; health.

## Главный барьер

New debt is collateralized funding, not flashloan profit.

## Первый эксперимент и критерий

One approved-position model; no borrower action. Метрика: Break-even holding time and post-switch health stress.
