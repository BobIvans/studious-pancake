# PR-353 shadow-only runbook

1. Keep every EVO package `DISABLED` in checked-in config.
2. Feed only already-admitted read-only evidence or synthetic/redacted fixtures.
3. Record observations, rejects, no-trades and typed failures, not only wins.
4. Build a `ResearchCandidate` only from rooted/finalized evidence and positive
   worst-case net after known costs.
5. Run replay, falsification and walk-forward qualification. The maximum state is
   `VERIFIED_SHADOW`.
6. EVO-09 may propose a preregistered hypothesis; it may not edit code/config or
   promote a strategy.
7. Do not load keys, sign, submit, fund, change provider resources or enable live
   effects.
8. Any future live experiment must use the pre-existing qualification, release,
   permit, signer and sender authorities in a separate explicitly authorized
   change.
