# CB-08 — Low-latency state → dependency invalidation → bounded search

**PROPOSED_NOT_RUN · P0 after exact baseline · infrastructure economics**

## Экономическое условие

Same admissible opportunities with lower end-to-end delay/CPU/data cost; correctness precedes microbench speed.

## Первый ограниченный эксперимент

Replay identical events through full recompute and dirty-subgraph path at 1x/10x/100x input load; record arrival-to-evidence p50/p95/p99, queue, misses, drops and backfill cost.

## Остановить или сузить

Only latency median improves while p99/stale errors worsen; true opportunities silently lost; access cost dominates.

## Возможный продукт

Market-state engine and shared evidence infrastructure. Спрос и доходность UNKNOWN.

## Совместимость

- Shortlist cutoff is explicit budget truncation unless a sound bound proves pruning.
- Preconfirmed state is a separate generation and commitment class.
