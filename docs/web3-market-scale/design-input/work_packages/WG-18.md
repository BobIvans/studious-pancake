# WG-18 — EVM и последующие settlement domains

Статус: **PLANNED_NOT_IMPLEMENTED**. Этап: D. Режим: shadow_only.

Зависимости: WG-02, WG-03, WG-05, WG-06, WG-10.

## Результат

Chain-qualified read-only state profile; сначала один EVM chain.

## Существующие владельцы

- O22: `src/market_data_evolution/contracts.py` — InstrumentIdentity; RawObservation; AvailabilityProof; StateSnapshot; ReplayManifest

## Шаги будущей реализации

1. Genesis/chain id, block hash/number, finality, reorg rollback, token code revision, factory registry и pool-state decoder.
2. Pin first chain/protocol pairs; chain RPC requests идут через existing governance/transport.
3. После EVM отдельные dossiers для Sui/Move/Cosmos/других сред, каждый со своей state/settlement semantics.

## Приёмка

- Same-address different-chain активы не совпадают.
- Cross-domain data можно видеть вместе, но global snapshot/atomic settlement не подразумеваются.

Сценарии: T59, T60, T61; определения в `../06_ACCEPTANCE_RU.md`.

## Ограничения

Один domain и один venue за proof; Solana graph owner не размывается цепочками строковых aliases.

## Когда остановить admission

Unknown finality/reorg/account model → reference/discovery only.

Не создаёт live authorization. Размер diff и оценку труда определить после обновления baseline; новые owner дубликаты не вводить.
