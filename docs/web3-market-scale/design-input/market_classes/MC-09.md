# MC-09 — Compute, inference и storage procurement

**PROPOSED_RND_NOT_RUN**, P1.

Разработчики solver/R&D workloads и data pipelines.

Resource broker: выбрать допустимую вычислительную услугу по delivered result cost, deadline и quality.

## Три продукта

- Clearing: Совместить batch задач с доступными time/resource slots; сохранять deadline/privacy/data locality constraints.
- Verified compute: Повторяемый результат и actual end-to-end resource usage; stochastic inference требует task-specific quality, не просто identical bytes.
- Mechanism lab: Compare posted/reverse auction, cancellation/refund и reservation policy на synthetic providers.

## Первый эксперимент

Одна deterministic route-evaluation job,3 provider profiles и outage/cold-start; compare local execution и procurement incl verification/transfer.

## Измерить

Cost per correct timely result, idle capacity, p95 latency, retry/verification overhead.

## Финансирование и время

Расходы периода услуги и оплаты, не atomic flashloan. Публичный marketplace не означает бесплатный compute.

## Ограничения и причины отказа

Hardware comparability, data rights/secrets, non-determinism, cancellation, provider independence и verification economics.

## Масштабирование

Множество клиентов и workloads при reuse task contracts; capacity по quality/location/time, не одному GPU ticker.
