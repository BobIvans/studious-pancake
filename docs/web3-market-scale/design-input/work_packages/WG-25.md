# WG-25 — Рынок проверяемых расчётов и данных

Статус: **PLANNED_NOT_IMPLEMENTED**. Этап: E. Режим: shadow_only.

Зависимости: WG-21, WG-22.

## Результат

Расширение existing INST-01 procurement arena на одну проверяемую услугу.

## Существующие владельцы

- O28: `src/research/pr359_wave15_institution.py` — InstitutionRuntime; SemanticEvidenceResolver; run_inst01_vertical
- O22: `src/market_data_evolution/contracts.py` — InstrumentIdentity; RawObservation; AvailabilityProof; StateSnapshot; ReplayManifest

## Шаги будущей реализации

1. Выбрать canonical decode/exact quote/replay task; task hash фиксирует data rights, inputs, deadline и verifiable output.
2. Добавить независимую recomputation и сравнение provider cost/latency/accuracy; не путать согласие двух копий одного источника с независимостью.
3. Проверить fixed-price/reverse auction baseline и спрос без субсидий в offline/добровольном исследовательском дизайне.

## Приёмка

- Unknown verification не оплачивается виртуально как success; duplicate task close идемпотентен.
- Нет заявления о живом спросе до фактических результатов.

Сценарии: T80, T81, T82; определения в `../06_ACCEPTANCE_RU.md`.

## Ограничения

Одна homogeneous service; only simulation of allocation/payment, no external messages or real marketplace payments.

## Когда остановить admission

Неверифицируемая услуга, утечка секретов или отсутствующие права на данные → excluded.

Не создаёт live authorization. Размер diff и оценку труда определить после обновления baseline; новые owner дубликаты не вводить.

Подробный следующий R&D: [три продукта](../11_RND_NEXT_3_PRODUCTS_RU.md), карточки `../rnd_three/`.
