# Provider Contract Exactness

## Goal
Runtime request and conformance probe must be generated by the **same typed request builder**.

### OpenOcean concrete bug
Current docs require `amountDecimals` and `gasPriceDecimals`. Repo conformance URL includes `gasPriceDecimals`, runtime request currently does not. Fix by one `OpenOceanQuoteRequestV4` serializer used by both runtime and probe.

## Every hosted API adapter must own
- endpoint generation;
- auth generation;
- required parameters;
- percent/amount units;
- response schema fingerprint;
- rate-limit contract;
- TTL/staleness contract;
- retry classes;
- negative HTTP handling;
- underlying venue identity;
- request/response hash.

## Drift policy
Any changed required field, auth mode, base URL or SDK major/minimum version creates a NEW source generation. Old campaign data remains replayable but cannot silently qualify the new generation.
