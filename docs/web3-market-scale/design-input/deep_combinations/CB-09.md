# CB-09 — Evidence providers → exact verifier → API procurement

**PROPOSED_NOT_RUN · P1 · data/compute service economics**

## Экономическое условие

Buyer value - source, compute, verification, retry, delivery and support costs; recurring unsubsidized demand required.

## Первый ограниченный эксперимент

Local verifier and 3 synthetic providers quote one identical CPMM task. Add wrong state, stale result, slow cheap result, shared upstream and duplicate receipt. Compare local-only baseline.

## Остановить или сузить

Verification cost exceeds saved compute; no buyer demand; reuse violates rights; paid receipt accepted as proof.

## Возможный продукт

Market Evidence API first; provider marketplace only after repeat demand and service economics. Спрос и доходность UNKNOWN.

## Совместимость

- x402 is an optional future billing adapter, not the verifier.
- Current INST-01 sum-int-v1 benchmark is not a ready arbitrary financial service market.
