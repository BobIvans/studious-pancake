# Первичные источники для обновления о масштабе

Прочитаны 2026-10-03. Это веб-документы и страницы первичного владельца метрики/интерфейса. Для protocol deployment/revision и raw payload нужна отдельная qualification. API probes, платные подключения и сделки не выполнялись.

| ID | Источник | Наблюдение | Вывод для проекта |
| --- | --- | --- | --- |
| MF-01 | [DefiLlama DEX dashboard](https://defillama.com/dexs) | Dashboard reports DEX turnover and protocol rankings; numerical capture is in money_flow_snapshot.json. | Rank discovery attention; this is not executable liquidity. |
| MF-02 | [DefiLlama derivatives dashboard](https://defillama.com/perps) | Reported and normalized volume are separate columns; open interest is a stock. | Keep metric definitions and revisions; do not infer flashloan capacity. |
| MF-03 | [DefiLlama stablecoins dashboard](https://defillama.com/stablecoins) | Stablecoin market capitalization is a stock of value. | Use as a settlement-asset discovery signal, not trading flow. |
| MF-04 | [DefiLlama lending dashboard](https://defillama.com/protocols/lending) | TVL, supplied assets and active loans are distinct columns. | Read each lender reserve separately for a funding decision. |
| MF-05 | [DefiLlama metric definitions](https://defillama.com/data-definitions) | DEX turnover aggregates trades; active loans are excluded from default TVL to limit looping inflation. | Prevent routed-volume and recycled-capital double counting. |
| MF-06 | [Jito account-lock auctions and bundle caveats](https://docs.jito.wtf/lowlatencytxnsend/) | Intersecting write/write or read/write account locks share auctions; read/read may separate. Rebroadcast from skipped blocks can lose bundle-level atomicity. | Use complete resource footprints and lender-scoped debt closure; bundle acceptance is not settlement. |
| MF-07 | [Solana transactions](https://solana.com/docs/core/transactions) | Instructions in a transaction succeed atomically; failed transactions can still incur fees. | Forecast failure costs and version transaction limits; no hardcoded future capacity promise. |
| MF-08 | [Ethereum transactions](https://ethereum.org/developers/docs/transactions/) | An account transaction nonce is sequential; gas payment is required. | Separate sender nonce lanes from parallel research workers and economic conflicts. |
| MF-09 | [Aave V3 flash loans](https://www.aave.com/docs/aave-v3/guides/flash-loans) | Multi-reserve flashLoan and single-reserve flashLoanSimple have different fee/debt options; the premium is governance-configurable. | Read actual reserve flags, balance, premium and callback terms. Debt conversion requires separate collateral or delegation. |
| MF-10 | [Morpho Blue flashLoan](https://docs.morpho.org/developers/contracts/blue/) | Blue documents access to the token balance of the contract, zero flash fee and a non-ERC-3156 interface. | Deduplicate a shared contract balance across markets; confirm deployment and token semantics. |
| MF-11 | [Balancer V3 flash loans](https://docs.balancer.fi/concepts/vault/flash-loans.html) | The current page describes V3 unlock, borrowing and settle within the transaction. | Do not apply old V2 ABI or fee assumptions to V3. |
| MF-12 | [Yellowstone gRPC](https://github.com/rpcpool/yellowstone-grpc) | Open-source Solana streaming service; repository displays AGPL-3.0. | Software availability is separate from hosting, validator access, data rights and operational costs. |
| MF-13 | [Helius LaserStream](https://www.helius.dev/docs/laserstream) | Mainnet access requires a Business or Professional plan; devnet availability is broader. | Paid optional feed, not an unlimited free mainnet source. Validate replay and delivery semantics before adoption. |
| MF-14 | [Binance Spot market streams](https://developers.binance.com/en/docs/catalog/core-trading-spot-trading/api/ws-streams/~) | The market-data interface includes depth snapshots and update identifiers. | A venue-specific synchronization procedure and depth coverage proof are required; no universal delta parser. |
| MF-15 | [Coinbase Exchange level2](https://docs.cdp.coinbase.com/exchange/websocket-feed/channels) | Level2 begins with a snapshot; an update size replaces the level size and zero removes the level. | Do not treat absolute sizes as additive deltas. Reconnect and full-channel sequencing differ. |
| MF-16 | [Hyperliquid WebSocket subscriptions](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/websocket/subscriptions) | l2Book parameters include precision and a fast mode; documented fast/slow depths are 5/20 levels. | Mark depth and precision coverage. A bounded book cannot certify fills beyond its visible depth. |
| MF-17 | [Geth real-time events](https://geth.ethereum.org/docs/interacting-with-geth/rpc/pubsub) | Subscriptions are connection-bound; reorgs can emit old logs with removed=true and repeat transactions. | Persist a recoverable cursor, backfill and reverse prior state before computing new evidence. |
| MF-18 | [Sui object model](https://docs.sui.io/develop/sui-architecture/object-model) | Object references bind ID, version and digest; transaction changes create new versions. | Track owned/shared object dependencies and gas objects as resources, not just token pairs. |
| MF-19 | [DefiLlama API services](https://api-docs.defillama.com/) | Free and Pro APIs have separate bases and authentication; free endpoints exist. | Choose documented free endpoints with quotas; do not accidentally route a job into paid paths. |
| MF-20 | [DEX Screener API reference](https://docs.dexscreener.com/api/reference) | Reference exposes discovery and pair endpoints with endpoint-specific rate limits. | Use for discovery and metadata, not amount-exact pool-state reconstruction. |
| MF-21 | [CoinGecko / GeckoTerminal documentation](https://docs.coingecko.com/) | The old GeckoTerminal guide redirects here; a free Demo API has limited endpoints and rate limits. | Verify the chosen API family, key requirement and plan; do not assume all onchain routes are free. |
| MF-22 | [The Graph query service](https://thegraph.com/docs/en/subgraphs/providers/subgraph-studio/introduction/) | The linked documentation includes billing for queries. | Indexing lag, schema revision and provider budget are part of the contract; unlimited free use is unverified. |
| MF-23 | [Dune API](https://docs.dune.com/api-reference/overview/introduction) | The API uses keys; metadata endpoints are listed as free. | Query execution and result access need separate credit/plan checks; use for slow historical research. |
| MF-24 | [Project 0 / former marginfi documentation entrypoint](https://docs.marginfi.com/) | The current homepage describes Project 0 on mrgnLendv2 with cross-venue collateral. | Treat naming/SDK drift as a qualification trigger, not automatic compatibility with a legacy lending adapter. |
| MF-25 | [Uniswap V3 flash guide](https://developers.uniswap.org/docs/protocols/v3/guides/flash-swaps/getting-started) | The V3 pool flash callback owes borrowed amounts plus fees within the transaction. | Bind lender pool locks and callback restrictions when composing swap legs. |
| MF-26 | [Kamino lending source repository](https://github.com/Kamino-Finance/klend) | The official public repository is available for code and revision qualification. | This review did not prove the deployed revision, flash fee, current reserve cash or full callback behavior. |

Дата чтения не равна дате публикации. Новизна протокола не выводится из recent crawl; страницы считаются актуальным design input, но не доказательством того, что продукт только что появился. Значения macro snapshots, определения и limitations — в [24_MONEY_FLOWS_AND_PRIORITIES_RU.md](24_MONEY_FLOWS_AND_PRIORITIES_RU.md).

Сводный catalog сохраняет ранее найденные sources; он не обещает исчерпывающий список всех поставщиков Web3. Политика доступа определяется конкретным endpoint/plan/terms, а не словом free в названии продукта.
