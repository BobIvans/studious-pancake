## Шаги будущей реализации

1. Цель: заданный asset/rights outcome при минимальных полных costs, а не только собственный arbitrage.
2. Совместить netting, transformations, inventory constraints и funding obligations с finite search.
3. Сравнить independent execution baseline с shared clearing; зафиксировать, кому принадлежит improvement и какие права нужны.

## Приёмка

- Все obligations и user limits соблюдены; surplus не удваивается.
- Продуктовая польза измеряется improvement after costs и воспроизводимостью, не backtest ROI.
