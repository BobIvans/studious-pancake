# CB-01 — Exact cycles → shared-state split-flow

**PROPOSED_NOT_RUN · P0 · conditional atomic research**

## Экономическое условие

Terminal settlement atoms minus repayment and non-embedded costs > 0 for an independently evaluated amount; shared state consumes liquidity once.

## Первый ограниченный эксперимент

Сначала 2 synthetic Solana CPMM routes с общим pool и 8 точными суммами: single vs disjoint split vs sequential shared-state split. Затем один квалифицированный новый AMM model, не все PX сразу.

## Остановить или сузить

Naive split gain исчезает при общем state; amount semantics не доказаны; ресурс или fee не учтён.

## Возможный продукт

Capacity & Route Evidence API; позже reusable exact adapters. Спрос и доходность UNKNOWN.

## Совместимость

- Внутри circular route повтор venue запрещён как прежде. Общий venue между разными paths требует state transition.
- Pool address, singleton address и liquidity alias — разные identities.
