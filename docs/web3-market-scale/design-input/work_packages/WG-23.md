# WG-23 — Интерфейс market-of-markets graph

Статус: **PLANNED_NOT_IMPLEMENTED**. Этап: C. Режим: shadow_only.

Зависимости: WG-02, WG-11, WG-22.

## Результат

Read-only UI с drill-down по domains, instruments, venues, transformations и evidence.

## Существующие владельцы

- O04: `src/strategy/arbitrage_graph.py` — UniversalArbitrageGraph; CircularGraphCandidateDetector; CircularShadowRoute
- O05: `src/strategy/market_graph_ingest.py` — ShadowMarketBinding; ShadowMarketGraphIngest

## Шаги будущей реализации

1. Сначала показать overview/coverage, затем bounded subgraph и exact capacity point.
2. Фильтры age, slot/generation, admission, exactness, settlement horizon, strategy family; rejected data доступно с reason.
3. Сравнить paths и costs; gross/net и quote freshness показывать рядом с суммой.

## Приёмка

- Статус stale/unknown нельзя принять за executable.
- Default экран не пытается отрендерить весь raw graph и не содержит connect-wallet/trade действий.

Сценарии: T74, T75, T76; определения в `../06_ACCEPTANCE_RU.md`.

## Ограничения

First UI page ≤200 nodes/500 edges как предлагаемая presentation policy; pagination и агрегаты явно отмечены.

## Когда остановить admission

Нет backend qualification — UI показывает planned/discovered, не trading-ready.

Не создаёт live authorization. Размер diff и оценку труда определить после обновления baseline; новые owner дубликаты не вводить.
