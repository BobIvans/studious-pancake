# CB-03 — Intents → netting → residual exact routing

**PROPOSED_NOT_RUN · P1 · clearing / service surplus**

## Экономическое условие

Same filled user obligations; each user meets limit and comparator; customer cost reduction and solver fee accounted separately.

## Первый ограниченный эксперимент

10 synthetic intents, 3 assets, 4 venues: independent feasible fills vs netting+residual routes. Include exclusivity, cancellation, partial fills and delayed order observation.

## Остановить или сузить

Aggregate surplus hides user loss; unavailable RFQ flow assumed; feed only recent orders treated as full market.

## Возможный продукт

Clearing quote/evidence API для wallets, treasury и intent builders. Спрос и доходность UNKNOWN.

## Совместимость

- Netting снижает промежуточную потребность в капитале, но не создаёт право распоряжаться чужими balances.
- Generic intent owner wrappers требуют реализации у существующего owner.
